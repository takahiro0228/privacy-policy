Doc Scribe

Privacy Policy / プライバシーポリシー

Last updated: 4 September 2026 ／ 最終更新日：2026年9月4日

English

1. Summary

Doc Scribe does not send any information to a server. It has no account system, no sign-in, no analytics, no advertising and no tracking. It works offline.

2. What is stored

The following is stored only in local extension storage (chrome.storage.local) on the user's device:

  • the title, description and step captions of each document
  • the page title and URL at the time of recording (this can be turned off in settings)
  • screenshots, with detected personal data masked
  • annotations added by the user, and the position of step-number markers
  • the extension's settings

3. What is not stored

  • the values typed into form fields
  • passwords and authentication credentials
  • cookies and access tokens
  • screens and browsing activity outside an active recording

4. Screenshots

Screenshots are taken only while a recording is in progress, at the moment the user performs an action. After capture, form fields, email addresses, phone numbers, postal codes and any words or CSS selectors specified by the user are masked.

When the setting "keep automatic masks editable" is enabled (the default), the unmasked image is retained in local storage so the user can reposition a mask later. That image is never transmitted either. Users who do not want any unmasked image retained can disable the setting; masks are then burned into the image before it is stored, and can no longer be repositioned.

5. Full-screen mode

If the user switches to full-screen recording, the standard screen-sharing API is used and Chrome asks the user to choose a screen or window. The video is held only in the extension's capture window, one frame is converted to an image, and the stream is then stopped. Automatic masking does not apply in this mode.

6. Third parties

No information is shared, sold or transferred to any third party. Nobody other than the user, including the developer, can access the recorded content.

7. Deletion

Documents can be deleted individually from the extension. Removing the extension from Chrome deletes all stored data.

8. Limits of automatic detection

Automatic detection of personal data is not perfect. Content drawn on a canvas element, inside an iframe, or embedded in an image may not be detected. Users are responsible for reviewing the preview and adding masks manually before exporting or sharing a document.

9. Permissions

Each permission requested by the extension is explained on its Chrome Web Store listing. All permissions serve the single purpose of recording, masking, editing and exporting procedure documents.

10. Contact

For inquiries, please contact through the public GitHub Issues page or the public contact email.

日本語

1. 基本方針

Doc Scribe（以下「本拡張機能」）は、利用者の情報を外部のサーバーへ送信しません。アカウント登録、ログイン、解析ツール、広告、トラッキングを一切使用しません。オフラインで動作します。

2. 保存する情報

以下を、利用者の端末のローカルストレージ（chrome.storage.local）にのみ保存します。

  • 手順書のタイトル、説明、各手順の説明文
  • 記録時のページタイトルとURL（設定で保存しないよう変更できます）
  • 個人情報をマスクしたスクリーンショット
  • 利用者が追加した注釈、および操作位置を示す番号枠の位置
  • 本拡張機能の設定

3. 保存しない情報

  • 入力欄に入力した文字列そのもの
  • パスワードおよび認証情報
  • Cookie およびアクセストークン
  • 記録していない間の画面および閲覧履歴

4. スクリーンショットの取り扱い

スクリーンショットは、記録中に利用者が操作を行った時点でのみ取得します。取得後、入力欄、メールアドレス、電話番号、郵便番号、および利用者が指定した語句・CSSセレクタに一致する領域をマスクします。

設定「自動マスクを後から編集できるようにする」が有効（初期値）の場合、マスクを後から動かせるようにするため、マスク前の画像がこの端末のローカルストレージに保持されます。この画像も外部へは送信されません。マスク前の画像を残したくない場合は、この設定を無効にしてください。無効にすると保存前に画像へマスクを焼き込むため、後から位置を修正できなくなります。

5. 画面全体モード

画面全体を撮るモードに切り替えた場合、ブラウザ標準の画面共有機能を使用し、共有する画面またはウィンドウの選択は Chrome が利用者に尋ねます。映像は本拡張機能の撮影ウィンドウだけで保持し、1コマを画像化した後に停止します。このモードでは自動マスクは働きません。

6. 第三者への提供

いかなる情報も第三者へ提供、販売、譲渡しません。開発者を含め、利用者以外の誰も記録内容にアクセスできません。

7. データの削除

手順書は本拡張機能の画面から個別に削除できます。Chrome から本拡張機能を削除すると、保存されたすべてのデータも削除されます。

8. 自動検出の限界について

個人情報の自動検出は完全ではありません。canvas による描画、iframe 内の要素、画像に埋め込まれた文字などは検出できない場合があります。利用者は、出力・共有の前にプレビューで内容を確認し、必要に応じて手動でマスクを追加する責任を負います。

9. 権限の使用目的

各権限の使用目的は Chrome ウェブストアの掲載ページに記載しています。すべての権限は、操作の記録・マスク・編集・出力という単一の目的のためにのみ使用します。

10. お問い合わせ

お問い合わせは、公開している GitHub Issues または公開メールアドレスをご利用ください。
GitHub Issues: https://github.com/takahiro0228/privacy-policy/issues
