Doc Scribe Privacy Policy

For inquiries, please contact through the public GitHub Issues page or the public contact email. GitHub Issues: https://github.com/takahiro0228/privacy-policy/issues

1. Scope

This Privacy Policy explains how the Doc Scribe Chrome extension (“Doc Scribe” or the “Extension”) handles user data. Doc Scribe creates editable, step-by-step guides from browser actions and screenshots.

2. Data handled by the Extension

Doc Scribe may handle the following data only when necessary to provide its guide-creation functionality:

  • visible screenshots captured while a user-started recording is active;
  • page titles and sanitized page URLs, if URL saving is enabled;
  • the type of recorded action, such as a click, input-field interaction, selection, navigation, or tab/window change;
  • labels, placeholders, roles, or tag names associated with the operated page element;
  • the location and size of the operated element and detected mask regions;
  • guide titles, guide descriptions, step instructions, annotations, inserted text, and inserted images supplied by the user;
  • Extension settings; and
  • local diagnostic information, including the Extension version, permission state, recent local event messages, and screenshot success or failure status.

Sanitized URLs exclude embedded usernames and passwords, query strings, and fragments. Doc Scribe does not access the user's complete Chrome browsing-history database.

Form input: Doc Scribe does not extract or save text typed into web form fields as a separate value. However, visible form content or other sensitive information may be present in a captured screenshot, including an original screenshot retained locally as described in Section 4.

3. How the data is used

The Extension uses the data only to:

  • create and display the guide requested by the user;
  • identify and mask potentially sensitive regions;
  • allow the user to edit, annotate, reorder, copy, save, back up, restore, and export the guide;
  • remember the user's local Extension settings; and
  • provide local diagnostics when the user requests troubleshooting information.

The data is not used for advertising, profiling, analytics, credit decisions, lending decisions, or any purpose unrelated to creating and managing the user's guides.

4. Screenshots and automatic masking

During an active recording, Doc Scribe captures the visible browser tab when a relevant user action or tab/window change occurs.

Doc Scribe can detect and cover text-entry fields, email addresses, phone numbers, postal codes, user-defined terms, and elements matched by user-defined CSS selectors. Automatic detection is not guaranteed to find every sensitive item.

Important: “Allow editing the automatic mask” is enabled by default. While this setting is enabled, the original unmasked screenshot is stored only in the user's local Chrome extension storage so the user can move, resize, or remove the mask later. Masks are applied to normal exports. A user who does not want unmasked screenshots retained locally must disable this setting before recording. When disabled, detected masks are permanently applied to the image before that image is stored, but the automatic masks cannot be repositioned later.

The editor also includes an “Original image (no masks)” function when an original image is available. Users must verify that an exported or copied image does not reveal sensitive information before sharing it.

Canvas content, cross-origin frames, text embedded in images, rapidly changing interfaces, or other technical conditions may prevent complete detection. Users are responsible for reviewing all screenshots and masks before exporting or sharing a guide.

5. Storage and transmission

Guide data and Extension settings are stored in chrome.storage.local within the user's Chrome profile. Doc Scribe does not operate an external storage server and does not transmit guide data, screenshots, browsing information, recorded actions, settings, or diagnostics to the developer or to third parties.

The Extension does not include analytics, advertising, tracking pixels, or remotely hosted code. Network requests made by the websites a user visits are controlled by those websites and are not transmissions by Doc Scribe.

6. Sharing and sale

The developer does not receive, sell, rent, share, or transfer user data. No third party is given access to data by Doc Scribe. Data leaves the Extension only when the user deliberately exports, copies, saves, or otherwise shares a guide or image.

7. Retention and deletion

Data remains in local extension storage until the user deletes an individual guide, resets or removes the relevant data, or uninstalls the Extension. Uninstalling Doc Scribe causes Chrome to remove the Extension's local storage. Files that the user has exported outside the Extension must be deleted separately by the user.

8. Security

Because data remains in the user's local Chrome profile, access depends on the security of the user's device, operating-system account, and Chrome profile. Users should lock their devices, restrict access to their Chrome profile, and review guides before exporting them. The developer cannot access or recover locally stored guides.

9. Chrome permissions

Doc Scribe uses Chrome permissions only to provide its single purpose of recording a browser workflow and creating, editing, and exporting a local visual guide. Permission details are disclosed in the Chrome Web Store listing.

10. Chrome Web Store Limited Use

The use of information received from Chrome APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

11. Changes to this policy

If Doc Scribe's data practices change, this policy and the Extension's disclosures will be updated before the new practices take effect. The effective date at the top of this policy will also be updated.

12. Contact

Questions about this policy may be sent to support@example.com.

Doc Scribe プライバシーポリシー

お問い合わせは、公開している GitHub Issues または公開メールアドレスをご利用ください。 GitHub Issues: https://github.com/takahiro0228/privacy-policy/issues

1. 適用範囲

本プライバシーポリシーは、Chrome拡張機能「Doc Scribe」（以下「本拡張機能」）が利用者データをどのように取り扱うかを説明します。本拡張機能は、ブラウザ操作とスクリーンショットから、編集可能な画像付き手順書を作成します。

2. 本拡張機能が扱うデータ

本拡張機能は、手順書作成機能の提供に必要な場合に限り、次のデータを扱うことがあります。

  • 利用者が開始した記録中に取得した、表示中の画面のスクリーンショット
  • URL保存が有効な場合のページタイトルと整形済みページURL
  • クリック、入力欄への操作、選択、ページ遷移、タブ／ウィンドウ切り替えなどの操作種別
  • 操作対象要素のラベル、プレースホルダー、role、タグ名
  • 操作対象要素および検出したマスク領域の位置と大きさ
  • 利用者が入力・追加した手順書タイトル、説明、各手順の操作説明、注釈、テキスト、画像
  • 本拡張機能の設定
  • 拡張機能のバージョン、権限状態、端末内の直近イベントメッセージ、撮影の成功／失敗状態などの端末内診断情報

整形済みURLからは、URLに埋め込まれたユーザー名とパスワード、クエリ文字列、フラグメントを除去します。本拡張機能は、Chromeの閲覧履歴データベース全体へアクセスしません。

フォームへの入力：本拡張機能は、Webフォームへ入力した文字列を独立した値として取得・保存しません。ただし、画面上に表示された入力内容その他の機密情報がスクリーンショットに含まれる場合があります。第4項のとおり、マスク前の画像が端末内に保持される場合もあります。

3. データの利用目的

本拡張機能は、データを次の目的に限り利用します。

  • 利用者が要求した手順書の作成と表示
  • 機密情報である可能性がある領域の検出とマスク
  • 手順書の編集、注釈、並べ替え、コピー、保存、バックアップ、復元、出力
  • 利用者が指定した拡張機能設定の端末内での保持
  • 利用者がトラブルシューティング情報を要求した場合の端末内診断

広告、プロファイリング、アクセス解析、信用力の判断、融資判断、または手順書の作成・管理と無関係な目的には利用しません。

4. スクリーンショットと自動マスク

記録中に対象となる操作またはタブ／ウィンドウの切り替えが行われた時点で、表示中のブラウザタブを撮影します。

入力欄、メールアドレス、電話番号、郵便番号、利用者が指定した語句、利用者が指定したCSSセレクタに一致する要素を検出し、覆うことができます。自動検出ですべての機密情報を検出できるとは限りません。

重要：「自動マスクを後から編集できるようにする」は初期状態で有効です。有効な間は、利用者が後からマスクを移動、サイズ変更または削除できるようにするため、マスク前の画像が利用者のChrome拡張機能用ローカルストレージにのみ保存されます。通常の出力物にはマスクが適用されます。マスク前の画像を端末内に残したくない利用者は、記録前にこの設定を無効にする必要があります。無効にすると、検出したマスクを画像へ焼き込んだ後で保存しますが、自動マスクの位置を後から変更できません。

元画像がある場合、編集画面には「元画像（マスクなし）」機能もあります。利用者は、出力またはコピーした画像に機密情報が含まれていないことを、共有前に確認する必要があります。

Canvas、クロスオリジンiframe、画像内の文字、急速に変化する画面、その他の技術的条件によって、完全に検出できない場合があります。利用者は、手順書を出力または共有する前に、すべてのスクリーンショットとマスクを確認する責任を負います。

5. 保存と送信

手順書データと拡張機能設定は、利用者のChromeプロファイル内にある chrome.storage.local へ保存されます。本拡張機能は外部保存サーバーを運営せず、手順書、スクリーンショット、閲覧に関する情報、記録した操作、設定、診断情報を開発者または第三者へ送信しません。

本拡張機能には、アクセス解析、広告、トラッキングピクセル、外部でホストされたコードは含まれません。利用者が閲覧するWebサイト自身による通信は各Webサイトが管理するものであり、本拡張機能による送信ではありません。

6. 第三者提供および販売

開発者は利用者データを受信、販売、貸与、共有または移転しません。本拡張機能が第三者へデータへのアクセスを提供することもありません。利用者が手順書または画像を意図的に出力、コピー、保存、共有した場合に限り、そのデータは本拡張機能の外へ移動します。

7. 保存期間と削除

利用者が個別の手順書を削除し、該当データをリセットまたは削除し、あるいは本拡張機能をアンインストールするまで、データは拡張機能のローカル保存領域に残ります。本拡張機能をアンインストールすると、Chromeが本拡張機能のローカル保存データを削除します。本拡張機能の外へ出力したファイルは、利用者が別途削除する必要があります。

8. セキュリティ

データは利用者のChromeプロファイル内に保存されるため、アクセスの安全性は利用者の端末、OSアカウント、Chromeプロファイルの安全性に依存します。利用者は、端末をロックし、Chromeプロファイルへのアクセスを制限し、出力前に手順書を確認してください。開発者は、端末内に保存された手順書へアクセスしたり復旧したりできません。

9. Chrome権限

本拡張機能は、ブラウザ操作を記録し、画像付き手順書を端末内で作成・編集・出力するという単一の目的のためにのみChrome権限を使用します。各権限の詳細はChromeウェブストアの掲載ページで開示します。

10. Chromeウェブストアの限定的利用要件

Chrome APIから受け取った情報の利用は、限定的利用要件を含むChromeウェブストアのユーザーデータポリシーに準拠します。

11. 本ポリシーの変更

本拡張機能のデータ取扱方法を変更する場合は、新しい取扱方法が有効になる前に、本ポリシーと本拡張機能の開示内容を更新します。また、本ポリシー上部の施行日も更新します。

12. お問い合わせ

本ポリシーに関するお問い合わせ先：support@example.com
